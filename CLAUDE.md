# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A React + TypeScript web application for annotating and evaluating 3D humanoid character animations. Uses the Agent Station Avatar SDK to display VRMA (VRM Animation) files and allows users to rate animations with quality, character type, and action tags.

## Commands

```bash
npm run dev              # Start Vite dev server with HMR
npm run build            # TypeScript compile + Vite production build
npm run build:prod       # Production build with correct base path for deployment
npm run lint             # Run ESLint
npm run preview          # Preview production build
npm run generate-manifest # Scan /animations directory and create public/animation-manifest.json
npm run deploy           # Build, upload to S3, and invalidate CloudFront cache
```

**Important**: Run `npm run generate-manifest` before first use or after adding new animation files.

## Architecture

### Data Flow
- **Animation Manifest**: Static JSON file (`public/animation-manifest.json`) generated by scanning `/animations` directory
- **Annotations**: Browser localStorage with JSON serialization, keyed by animation path
- **Cloud Sync** (optional): When `VITE_API_URL` is configured, annotations sync to DynamoDB via API Gateway
- **Avatar SDK**: CDN-hosted @agent-station/avatar-web renders VRMA files

### Key Components
- **App.tsx**: State orchestrator (current animation, filters, playback control)
- **AvatarViewer.tsx**: Avatar SDK integration, handles animation loading/playback
- **AnnotationPanel.tsx**: Annotation controls with keyboard shortcuts
- **AnimationList.tsx**: Filterable sidebar with animation entries
- **SyncStatusBar.tsx**: Cloud sync status indicator with retry functionality

### Custom Hooks
- **useAnimationList.ts**: Fetches manifest, applies pack/category/status filters
- **useAnnotations.ts**: localStorage CRUD operations, import/export, cloud sync integration
- **useSyncStatus.ts**: Cloud sync state management and status tracking

### Services
- **annotationApi.ts**: REST API client for cloud annotation persistence
- **syncQueue.ts**: Offline-first sync queue with retry logic (localStorage-backed)

### Type Definitions
All types in `src/types/index.ts`:
- `Quality`: 'approved' | 'rejected' | 'maybe'
- `Character`: 'sarang' | 'yeona' | 'other' | 'none'
- `ActionTag`: 'idle' | 'greeting' | 'reaction' | 'conversation' | 'locomotion' | 'combat'

## Keyboard Shortcuts

### Annotation (in AnnotationPanel)
- **1/2/3**: Quality (approved/rejected/maybe)
- **S/Y/O/N**: Character (Sarang/Yeona/Other/None)
- **I/G/R/C/L/X**: Toggle tags (idle/greeting/reaction/conversation/locomotion/combat)

### Navigation & Playback
- **Enter/Arrows**: Navigate animations
- **Space**: Replay current animation
- **P**: Pause/Play toggle

### Global (in App)
- **?**: Show keyboard shortcuts help
- **Ctrl+Z / Cmd+Z**: Undo last annotation change
- **Ctrl+Shift+Z / Cmd+Shift+Z / Ctrl+Y**: Redo
- **Escape**: Close help modal

## Animation Files

VRMA files must be placed in `/animations/{pack}/{category}/` structure. The manifest generator walks this directory to build metadata. Animations are served from the public path `/animations/`.

## Environment Variables

| Variable | Description |
|----------|-------------|

## Deployment

The app is deployed to AWS S3 with CloudFront CDN.

**Production URL**: https://avatars.staging.agsn.ai/apps/animation-reviewer/

```bash
npm run deploy           # Build, upload to S3, and invalidate CloudFront (recommended)
npm run deploy:s3        # Upload dist/ to S3 only
npm run deploy:invalidate # Invalidate CloudFront cache only
npm run deploy:infra     # Deploy backend infrastructure (CDK)
```

**Note**: The deploy scripts use `AWS_PROFILE=agent-station-staging` automatically.

### Deployment Details

- **S3 Path**: `/apps/animation-reviewer/`

## Cloud Infrastructure

AWS infrastructure is defined in `/infra` using CDK.

**AWS Profile**: Use the `agent-station-staging` profile for infrastructure deployments:

```bash
AWS_PROFILE=agent-station-staging npm run deploy:infra # Deploy backend infrastructure only
```

### Stacks

**AnimationReviewerStack** - Backend API:
- **DynamoDB**: `animation-reviewer-annotations` table with GSI for time-based queries
- **Lambda**: Node.js 20 function handling API requests
- **API Gateway**: REST API with CORS, throttling, and gzip compression

### API Endpoints
| Method | Path | Description |
|--------|------|-------------|
| GET | `/annotations/{userId}` | Get all annotations (supports `?updatedSince=`) |
| GET | `/annotations/{userId}/{path}` | Get single annotation |
| PUT | `/annotations/{userId}/{path}` | Create/update annotation |
| DELETE | `/annotations/{userId}/{path}` | Delete annotation |
| POST | `/annotations/batch/{userId}` | Batch import annotations |
