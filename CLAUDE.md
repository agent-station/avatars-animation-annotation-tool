# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A React + TypeScript web application for annotating and evaluating 3D humanoid character animations. Uses the Agent Station Avatar SDK to display VRMA (VRM Animation) files and allows users to rate animations with quality, character type, and action tags.

## Commands

```bash
npm run dev              # Start Vite dev server with HMR
npm run build            # TypeScript compile + Vite production build
npm run lint             # Run ESLint
npm run preview          # Preview production build
npm run generate-manifest # Scan /animations directory and create public/animation-manifest.json
```

**Important**: Run `npm run generate-manifest` before first use or after adding new animation files.

## Architecture

### Data Flow
- **Animation Manifest**: Static JSON file (`public/animation-manifest.json`) generated by scanning `/animations` directory
- **Annotations**: Browser localStorage with JSON serialization, keyed by animation path
- **Avatar SDK**: CDN-hosted @agent-station/avatar-web renders VRMA files

### Key Components
- **App.tsx**: State orchestrator (current animation, filters, playback control)
- **AvatarViewer.tsx**: Avatar SDK integration, handles animation loading/playback
- **AnnotationPanel.tsx**: Annotation controls with keyboard shortcuts
- **AnimationList.tsx**: Filterable sidebar with animation entries

### Custom Hooks
- **useAnimationList.ts**: Fetches manifest, applies pack/category/status filters
- **useAnnotations.ts**: localStorage CRUD operations, import/export

### Type Definitions
All types in `src/types/index.ts`:
- `Quality`: 'approved' | 'rejected' | 'maybe'
- `Character`: 'sarang' | 'yeona' | 'other' | 'none'
- `ActionTag`: 'idle' | 'greeting' | 'reaction' | 'conversation' | 'locomotion' | 'combat'

## Keyboard Shortcuts (in AnnotationPanel)

- **1/2/3**: Quality (approved/rejected/maybe)
- **S/Y/O/N**: Character (Sarang/Yeona/Other/None)
- **I/G/R/C/L/X**: Toggle tags (idle/greeting/reaction/conversation/locomotion/combat)
- **Enter/Arrows**: Navigate animations
- **Space**: Replay current animation

## Animation Files

VRMA files must be placed in `/animations/{pack}/{category}/` structure. The manifest generator walks this directory to build metadata. Animations are served from the public path `/animations/`.
